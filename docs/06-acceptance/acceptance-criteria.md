# 验收标准

## 功能验收

MVP 完成后应该满足：

- 首次安装后，可以完成 onboarding，并进入首页。
- 首页能明确显示今晚目标睡觉时间、剩余时间和今日状态。
- 用户能确认今晚早睡契约。
- 用户能完成今日复盘，把今天和明天的事情分开记录。
- 用户能进入睡前模式，并完成睡前 checklist。
- 用户想继续刷手机时，能进入破防急救，并记录一次补救。
- 用户能看到最近 7 天记录、连续早睡天数、已解锁徽章。
- 用户能在设置页修改目标时间、提醒时间，并清空数据。
- 关闭并重新打开 App 后，所有本地数据仍然存在。

## 体验验收

产品体验应该满足：

- 语气温柔但有约束感。
- 文案接地气，不像训人。
- 不使用医疗化、诊断式表达。
- 不使用空泛鸡汤。
- 用户破防时能看到补救入口，而不是失败提示。
- 核心流程 1 分钟内可以演示完整。

## 核心演示路径

```txt
首次配置
→ 首页看到倒计时
→ 确认早睡契约
→ 写今日复盘
→ 进入睡前模式
→ 中途点破防急救
→ 选择补救成功
→ 查看记录和徽章
```

## 技术验收

- TypeScript 无明显类型错误。
- 页面跳转无崩溃。
- 本地数据读写稳定。
- 倒计时显示正确。
- 清空数据功能可恢复到首次进入状态。
- 本地提醒开关不会造成重复注册提醒。
