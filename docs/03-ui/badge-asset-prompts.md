# 徽章资产生成提示词

## 生成规格

- 尺寸：1024x1024
- 格式：PNG
- 背景：透明背景
- 图中不要文字、字母、数字
- App 内文字由组件渲染，不放进图片

## 统一风格母提示词

```text
A soft mobile app achievement badge icon for a sleep self-care app, transparent background, centered composition, rounded emblem silhouette, dreamy midnight palette, warm moonlight gold, muted lavender blue, soft mint accents, gentle glassmorphism glow, subtle depth, premium wellness app style, calm and non-gamey, no text, no letters, no numbers, no trophy, no medal ribbon, no harsh contrast, no cartoon face, clean edges, suitable for React Native app asset, 1024x1024 PNG
```

## 负向提示词

```text
text, letters, numbers, logo, watermark, trophy, medal ribbon, crown, sports badge, aggressive game achievement, neon cyberpunk, medical symbol, hospital icon, alarm clock, phone screen, emoji, flat sticker, harsh outline, busy background, square background, white background
```

## 选择建议

每个徽章建议生成 2-3 张候选。优先选择：

- 透明底干净
- 中心构图稳定
- 图形不要太复杂
- 小尺寸下仍能看清主题
- 颜色与当前 App 的深夜、月光金、薰衣草蓝、薄荷绿一致
