# 页面与路由结构

## 路由总览

```txt
/
/onboarding
/contract
/review
/bedtime
/rescue
/records
/badges
/settings
```

## 页面说明

### /onboarding

首次进入页面。

用途：

- 选择目标睡觉时间
- 选择起床时间
- 选择熬夜原因
- 保存用户配置

完成后跳转到首页。

### /

首页。

用途：

- 展示今晚目标睡觉时间
- 展示倒计时
- 展示今日状态
- 提供核心功能入口

首页应该是用户晚上打开 App 最常看的地方。

### /contract

早睡契约页。

用途：

- 确认今晚几点前睡
- 保存今日计划睡觉时间
- 更新今日状态

### /review

今日复盘页。

用途：

- 记录今日主要事件
- 记录今日收获
- 记录明日想做 / 想玩的事情
- 帮助用户完成“今天收尾”

### /bedtime

睡前模式页。

用途：

- 显示睡前倒计时
- 展示睡前 checklist
- 用户点击“我准备睡了”

### /rescue

破防急救页。

用途：

- 用户想继续刷手机时进入
- 展示短句提醒
- 提供替代行动
- 记录补救成功

### /records

睡眠记录页。

用途：

- 查看最近 7 天趋势
- 查看连续早睡天数
- 查看每日记录

### /badges

徽章页。

用途：

- 展示已解锁徽章
- 展示未解锁徽章
- 说明解锁条件

### /settings

设置页。

用途：

- 修改目标睡觉时间
- 修改起床时间
- 修改提醒设置
- 清空本地数据
