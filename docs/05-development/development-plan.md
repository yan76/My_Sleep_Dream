# 开发步骤

## 任务 1：初始化项目与基础导航

目标：

- 创建 Expo + TypeScript 项目
- 接入 Expo Router
- 建立所有页面空壳

验证：

- App 可以启动
- 可以从首页跳转到每个页面
- 页面返回正常

## 任务 2：建立数据模型与本地存储

目标：

- 定义核心 TypeScript 类型
- 封装 AsyncStorage
- 建立 Zustand store
- 支持初始化、保存、读取

验证：

- 修改用户配置后关闭 App 再打开，数据仍然存在
- 清空数据后恢复初始状态

## 任务 3：完成首次进入流程

目标：

- 实现 onboarding 页面
- 支持选择睡觉时间、起床时间、熬夜原因
- 完成后写入用户配置

验证：

- 首次打开进入 onboarding
- 完成后进入首页
- 再次打开不再进入 onboarding
- 清空数据后重新进入 onboarding

## 任务 4：完成首页与早睡契约

目标：

- 首页展示今晚目标睡觉时间
- 首页展示倒计时
- 首页展示今日状态
- 契约页可确认今晚睡觉时间

验证：

- 首页倒计时正常更新
- 确认契约后状态变为已立约
- 今日记录中保存计划睡觉时间

## 任务 5：完成今日复盘与睡前模式

目标：

- 复盘页保存今日事件、收获、明日想做的事
- 睡前模式展示 checklist 和倒计时
- 用户可点击“我准备睡了”

验证：

- 复盘内容保存后重新进入仍存在
- checklist 状态可以保存
- 点击“我准备睡了”后今日状态更新

## 任务 6：完成破防急救

目标：

- 展示随机急救短句
- 展示替代行动
- 记录补救成功

验证：

- 点击补救成功后 `rescueCount` 增加
- 今日状态变为已补救
- 首页能展示补救状态

## 任务 7：完成记录、趋势和徽章

目标：

- 展示最近 7 天记录
- 计算连续早睡天数
- 实现徽章解锁

验证：

- 模拟多天记录后趋势展示正确
- 连续天数计算正确
- 达成条件后徽章解锁

## 任务 8：完成设置和提醒

目标：

- 设置页修改目标睡觉时间、起床时间、提醒时间
- 支持开启 / 关闭提醒
- 支持清空本地数据

验证：

- 修改设置后首页展示更新
- 本地提醒可以注册
- 清空数据后回到 onboarding
