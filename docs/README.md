# 早睡自救局文档中心

《早睡自救局》是一款面向经常晚睡、刷手机停不下来、晚睡后有负罪感但又很难改变的用户的早睡督促 App。

它不是严厉打卡工具，而是一个“温柔但有约束感”的自救型 App。产品语气要接地气、有陪伴感，不鸡汤，不医疗化。

## 第一版目标

第一版只做能跑起来、能演示核心体验的版本：

1. 首次进入完成早睡目标配置。
2. 首页展示今晚目标、倒计时和今日状态。
3. 用户能确认早睡契约。
4. 用户能做今日复盘，把今天和明天分开收尾。
5. 用户能进入睡前模式，按 checklist 收手机。
6. 用户破防时能进入急救流程并记录补救。
7. 用户能查看简单记录、连续天数和徽章。
8. 用户能在设置中修改目标和清空数据。
