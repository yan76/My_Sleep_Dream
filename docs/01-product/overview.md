# 产品概览

## 产品名称

早睡自救局

## 产品定位

早睡自救局不是一个监督用户早睡的工具，也不是一个严厉的打卡 App。

它是一款睡前陪伴型产品：每天晚上帮助用户结束今天、放下情绪、进入睡意；第二天早上帮助用户看见自己正在变好。

产品核心不是“管住用户”，而是“在用户最容易滑走的夜晚，把他温柔地带回来一点”。

## 核心体验

用户每天经历一条完整闭环：

```txt
首页判断当前状态
-> 开始自救流程
-> 收住外界刺激
-> 写下今日故事、遗憾与明日计划
-> 进入助眠内容
-> 确认准备睡觉
-> 次日打卡
-> 查看昨晚反馈
-> 在成长页看见长期变化
```

这条路径要让用户感到：

- 今晚不是又失败了，而是还可以被带回来。
- 今日复盘不是任务，而是把今天放下的心理仪式。
- 助眠内容不是附属工具，而是帮助自己进入睡意的核心服务。
- 成长不是徽章收集，而是持续看见“我真的在变好”。

## 目标用户

目标用户是经常晚睡、刷手机停不下来、晚睡后有负罪感但又很难改变的人。

典型状态：

- 白天很累，晚上却舍不得睡。
- 明知道该停下，但还是想再刷一会儿。
- 今天有故事、有遗憾、有没做完的事，睡前脑子停不下来。
- 不喜欢被强制管理，但需要一个温柔、有边界的外部陪伴。
- 希望自己变好，但不想每天被成功/失败审判。

## 产品情绪基调

关键词：

- 温柔
- 有边界
- 接住情绪
- 帮用户收尾
- 不羞辱失败
- 强化真实变化
- 有一点东方睡前仪式感，但不故作玄虚

## 底部导航

底部导航固定为四个一级入口：

### 首页

首页是状态中枢。

用户打开 App 后，不需要自己判断该点哪个功能，首页只给一个最重要的主行动。

首页负责回答：

```txt
我现在最该做什么？
```

### 自救

自救是睡前主流程。

它包含三段：

1. 收住外界
2. 把今天放下
3. 进入睡意

自救不是危机感很重的“抢救”，而是夜晚里把自己带回来的行动。

### 成长

成长承载用户的长期正反馈。

它不以徽章墙为主，而是用趋势、具体事实、身体感受和周总结，让用户看见：

```txt
我不是突然变自律了，我是真的一点点在变好。
```

### 设置

设置承载目标、提醒、晚睡原因、助眠偏好和数据管理。

设置不参与主流程抢入口。

## 核心页面

第一阶段原型与开发围绕以下页面展开：

1. 首页
2. 自救流程
3. 今日复盘
4. 睡意生成器
5. 声音 Spa
6. AI 树洞预设
7. 下线挑战
8. 次日打卡
9. 昨晚反馈
10. 成长页
11. 周总结
12. 设置页

## 商业化预设

付费能力的核心不是“卖白噪音”，而是卖更有效的睡前陪伴与睡意生成。

后续可扩展：

- 个性化心理暗示音频
- 根据今日复盘生成专属晚安语
- AI 树洞陪聊
- ASMR/AMSR 助眠内容库
- 个性化睡前脚本
- 周总结与长期变化报告增强

第一阶段可以先做入口、占位和基础体验，但信息架构必须提前为这些能力预留主位置。
