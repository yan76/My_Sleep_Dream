# 产品概览

## 产品名称

早睡自救局

## 目标用户

经常熬夜、刷手机停不下来、晚睡后有负罪感但又很难改变的人。

典型状态：

- 白天很累，晚上却舍不得睡。
- 明知道该睡了，但还是想再刷一会儿。
- 晚睡后后悔，但第二天继续重复。
- 不喜欢被强制管控，但需要一点外部约束。

## 产品定位

早睡自救局不是医疗睡眠管理工具，也不是严厉打卡工具。

它更像一个晚上陪用户“收尾”的小助手：

- 温柔提醒，但不纵容继续拖延。
- 承认用户会破防，但提供补救路径。
- 不制造羞耻感，而是帮助用户把今晚拉回来一点。
- 不追求完美早睡，而是鼓励“比昨天少熬一点”。

## 核心体验

用户每天晚上经历一条完整路径：

```txt
确认今晚几点睡
→ 复盘今天
→ 把明天想做的事记下来
→ 进入睡前模式
→ 破防时急救
→ 第二天看到记录和反馈
```

## 产品关键词

- 温柔
- 有边界
- 接地气
- 自救
- 收尾感
- 补救而不是失败
