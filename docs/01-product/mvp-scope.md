# MVP 功能范围

## MVP 原则

第一版只做能演示核心体验的功能，不做复杂系统。

要优先跑通这一件事：

```txt
用户今晚想晚睡时，App 能帮他完成收尾、降低继续刷手机的冲动，并留下记录。
```

## 必做功能

### 1. 首次进入

用户第一次打开 App 时配置：

- 目标睡觉时间
- 起床时间
- 熬夜原因

熬夜原因建议选项：

- 短视频
- 社交软件
- 游戏
- 追剧 / 看小说
- 工作 / 学习
- 报复性熬夜
- 焦虑停不下来
- 其他

### 2. 首页

首页展示：

- 今晚目标睡觉时间
- 距离目标睡觉的倒计时
- 今日状态
- 早睡契约入口
- 今日复盘入口
- 睡前模式入口
- 破防急救入口
- 睡眠记录入口

今日状态：

- 未开始
- 已立约
- 已复盘
- 睡前模式中
- 按时睡
- 晚睡
- 已补救

### 3. 早睡契约

用户确认今晚几点前睡。

允许：

- 使用默认目标睡觉时间
- 临时提前
- 临时延后

保存内容：

- 今日计划睡觉时间
- 契约确认时间
- 今日状态改为已立约

### 4. 今日复盘

用户记录：

- 今日主要事件
- 今日收获
- 明日想做 / 想玩的事情

目标不是写日记，而是制造“今天已经结束”的心理收尾。

### 5. 睡前模式

包含：

- 睡前倒计时
- 睡前 checklist
- “我准备睡了”按钮

Checklist：

- 放下手机
- 洗漱
- 灯光调暗
- 明天的事已经记下

### 6. 破防急救

当用户还想继续刷手机时进入。

提供：

- 一句短提醒
- 替代行动
- 记录补救成功

替代行动：

- 只刷最后 3 分钟
- 起来喝水
- 把想看的内容记到明天
- 直接进入睡前模式

### 7. 睡眠记录

记录：

- 是否按时睡
- 连续早睡天数
- 最近 7 天趋势
- 每日简单状态

### 8. 激励系统

徽章类型：

- 第一次立约
- 第一次按时睡
- 连续 3 天早睡
- 连续 7 天早睡
- 第一次破防补救
- 本周熬夜减少

### 9. 设置页

支持：

- 修改目标睡觉时间
- 修改起床时间
- 修改提醒时间
- 开关提醒
- 清空数据

## 暂不做功能

- 登录注册
- 云同步
- 社交监督
- 复杂睡眠分析
- 真实睡眠检测
- 医疗建议
- AI 对话
- 付费系统
