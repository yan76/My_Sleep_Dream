# 产品文案与语气

## 语气原则

早睡自救局的语气应该像一个懂你但不惯着你的朋友。

要做到：

- 温柔，但有边界。
- 接地气，但不油腻。
- 有陪伴感，但不鸡汤。
- 承认破防，但给出补救。
- 避免医疗化表达。

不要出现：

- “你必须”
- “你又失败了”
- “长期熬夜会导致严重后果”
- “自律改变人生”
- “坚持就是胜利”

## 推荐表达

首页：

```txt
今晚目标：23:30 前睡。
离收手机还有 42 分钟。
今天已经够满了，等会儿把尾收一下就行。
```

早睡契约：

```txt
今晚先定一个能做到的时间。
不是发誓改命，是给今晚一个边界。
```

今日复盘：

```txt
把今天放在这里，明天再继续。
想玩的、想做的，也先存起来。
不是不做，是不用今晚硬撑着做。
```

睡前模式：

```txt
现在开始收尾。
手机不用立刻变消失，但先别再开新的一局。
```

破防急救：

```txt
你不是没救，只是现在有点停不下来。
先别加码，我们把今晚往回拉一点。
```

补救成功：

```txt
很好，今晚没有彻底滑走。
能拉回来一点，就算自救成功。
```

晚睡记录：

```txt
昨晚晚了点。
不用补骂自己，今晚少拖一点就行。
```

## 文案风格检查

每句文案上线前检查：

- 是否像人在说话？
- 是否避免羞辱用户？
- 是否给了下一步行动？
- 是否没有医学诊断感？
- 是否没有空泛鸡汤？
