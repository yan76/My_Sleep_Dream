# 2026-05-29

## 修复：卡片顶部色带/杂色问题

### 第一轮（rgba → hex）
将所有 `rgba()` 半透明色替换为等效实体 hex。

### 第二轮（View 级 opacity + overflow + 渐变）
移除所有 View 级 `opacity`，用 8 位 hex 替代；修复 AppButton 渐变重叠；添加 `renderToHardwareTextureAndroid`。

### 第三轮（移除所有卡片/组件边框）
**问题仍存在**。进一步根因：1px 细边框 + 大圆角在深色背景上产生抗锯齿伪影。Web/原生渲染器在处理 border+radius 组合时会产生子像素渲染伪影，在深色背景下尤为明显。

**修复**：移除所有卡片/芯片/按钮式 UI 元素的 `borderWidth` + `borderColor`，同时清理孤立的 `borderColor` 引用。
